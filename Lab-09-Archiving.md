# \# Lab 09: Archiving \& Data Compression



## \## Objective

Demonstrate knowledge of creating, listing, extracting, and compressing archive files in Linux systems for backup and system administration workflows.



### \## Practical Tasks Completed

##### 1\. \*\*Archive Creation \& Compression:\*\*

&#x20;  - Bundled directories using `tar` (`-cvf`).

&#x20;  - Applied compression formats: Gzip (`.tar.gz`), Bzip2 (`.tar.bz2`), and XZ (`.tar.xz`).

##### 2\. \*\*Archive Inspection \& Extraction:\*\*

&#x20;  - Inspected archive contents without extracting using `tar -tvf`.

&#x20;  - Extracted archive bundles to targeted backup paths using `tar -xvf`.

##### 3\. \*\*ZIP Management:\*\*

&#x20;  - Managed zip files and archives using `zip` and `unzip` utilities for cross-platform compatibility.
