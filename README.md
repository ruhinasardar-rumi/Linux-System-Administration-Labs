# 🐧 Hands-On Linux System Administration & Cloud Foundations

Welcome to my Linux System Administration portfolio! This repository showcases a comprehensive collection of practical, terminal-based labs focused on Linux administration, shell scripting, networking, security, and resource management. These hands-on labs reflect core technical competencies for **Junior Cloud Administrator**, **IT Support Analyst**, and **Cloud Infrastructure** roles.

## 🛠️ Key Technical Skills Demonstrated

- **Identity Management:** User/group provisioning, password policies, privilege delegation (`/etc/sudoers`).
- **Security & Access Control:** POSIX file permissions, special sticky bits, ownership inheritance.
- **Troubleshooting:** CPU/Memory usage inspection, process management, log tracking (`/var/log`).
- **Automation & Scripting:** Writing modular Bash scripts and utilizing shell I/O redirection for efficient systems administration. Bash scripts with logic gates and loops.
