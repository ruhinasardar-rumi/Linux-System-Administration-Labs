# Lab 11: Text Editing & Shell Scripting

## Objective

Develop Shell scripts using standard logic structures (`if`, `while`, `for`) and edit configuration files using command-line editors like `vi`/`vim`.

---

## Key Concepts & Script Implementations

### 1. Text Editing (`vi`/`vim`)
- Navigated modes (Command vs Insert), performed line editing, pattern searches, and saved configurations safely.

### 2. Automated Bash Scripts
- Created executable `.sh` files with conditional branching (`if-then-else`).
- Implemented `for` loops for bulk file processing and `while` loops for continuous monitoring.
