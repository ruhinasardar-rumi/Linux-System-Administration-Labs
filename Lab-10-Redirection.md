# \# Lab 10: I/O Redirection \& Text Processing



## \## Objective

Process system logs and text streams efficiently using standard input, output, error streams, piping, and text utilities.



### \## Key Executed Workflows

##### 1\. \*\*Redirection Mechanics:\*\*

&#x20;  - Redirected command outputs to new log files using `>`.

&#x20;  - Appended system outputs without overwriting using `>>`.

&#x20;  - Filtered errors using Standard Error (`2>`) redirection.

##### 2\. \*\*Piping \& Filtering:\*\*

&#x20;  - Combined commands using pipelines (`|`) to stream data between processes.

&#x20;  - Used `grep` for pattern matching, `cut` for column extraction, and `sort` / `uniq` for data aggregation.
