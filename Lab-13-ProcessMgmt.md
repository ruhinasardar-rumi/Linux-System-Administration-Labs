# Lab 13: Process & Resource Management

## Objective

Monitor running processes, manage background/foreground tasks, control process priorities, and troubleshoot system resource spikes.

---

## System Management Operations

### 1. Process Tracking
- Monitored real-time system performance using `top`.
- Listed detailed process trees using `ps aux` and `ps -ef`.

### 2. Job Control & Signals
- Moved active execution jobs between foreground and background (`fg`, `bg`, `jobs`).
- Terminated unresponsive processes using process signals via `kill` and `killall`.
